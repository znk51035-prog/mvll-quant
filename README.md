# mvll-quant

MVLL（GraniteShares 2x MRVL 每日杠杆 ETF）量化策略：回测、前向验证与每日信号。

## 当前锁定策略（前向验证中）

纯 Donchian：收盘突破前 20 日最高点买入，收盘跌破前 10 日最低点卖出；
无固定止盈止盈；每笔 $5000 名义，只做多，连续亏损 3 次熔断停开新仓。

## 文件

- `strategy.py` —— 主程序。三种模式：
  - `python3 strategy.py backtest`：第一版（5/20 均线）全历史回测
  - `python3 strategy.py daily`：每日收盘后运行，刷新数据并更新虚拟账本 `ledger.json`
  - `python3 strategy.py signal`：输出当日信号
- `backtest_v2.py` —— 第二版：MACD / KDJ / MACD+KDJ 共振对比
- `backtest_v3.py` —— 第三版：全网调研 5 个候选组合实测（R1~R5）

## 回测结论（2025-03-07 ~ 2026-10-06，Yahoo 复权日线）

| 版本 | 策略 | 收益 |
|---|---|---|
| v1 | 5/20 均线 + 固定止盈止损 | +$1,028 |
| v2 | KDJ 超卖金叉（最优） | +$2,395 |
| v3 | R4 Donchian(20) 突破 + 2×ATR | +$20,359 |
| v3 | 纯 Donchian（无固定止损） | +$19,693 |

核心发现：固定 +10% 止盈是利润杀手；去掉它、让趋势决定出场，收益打开一个数量级。
R4 参数敏感性检验（9 组参数）全部 +19%~+21%，非过拟合。

注意：利润几乎全来自 2026-03~07 一波大趋势，属一波流；最大回撤约 18%。
数据：Yahoo Finance 日线（adjclose 复权，含 2026-06-26 的 3:1 拆股）。
